# Project Brief (Original Assignment)

This is the verbatim assignment brief this repository scaffolds. Keep it as the
source of truth for scope; the module docs in `docs/modules/` break it down into
actionable steps.

## Overview

Students will build a production-ready, multi-modal AI assistant combining
Retrieval-Augmented Generation (RAG) for intelligent question answering, text
generation using transformers, and image generation using diffusion models. This
capstone project integrates all previous learnings into a deployable application.

## Business Context

Modern AI assistants must handle multiple modalities — text, images, and structured
data — while providing accurate, contextual responses. This project simulates
building an enterprise-grade AI platform that could serve customer support, content
creation, or knowledge management use cases in real businesses.

## Learning Objectives

- Retrieval-Augmented Generation (RAG) implementation
- Vector databases and semantic search
- Fine-tuning transformer models for specific domains
- Diffusion models for image generation (Stable Diffusion)
- Full-stack development (Backend API, Frontend interface)
- Cloud deployment (Docker, Kubernetes, AWS/GCP/Azure)
- MLOps practices and production considerations

## Datasets & Resources

- **Knowledge Base Dataset**: SQuAD 2.0 or MS MARCO (for RAG implementation) — https://rajpurkar.github.io/SQuAD-explorer/
- **Text Generation**: fine-tune on a domain-specific corpus or use a HuggingFace dataset
- **Image Generation**: Stable Diffusion v2.1 or DALL·E API
- **Vector Database**: LanceDB, Pinecone, or Weaviate

## Deliverables

1. Complete codebase: GitHub repository with well-organized, documented code
2. Deployed application: live, accessible web application with a public URL
3. Technical documentation (20–25 pages): system architecture, API documentation, deployment guide, performance analysis
4. User guide & API documentation: complete user manual and API reference
5. Presentation (15–20 minutes): live demonstration, technical deep-dive, lessons learned
6. Demo video (8–10 minutes): recorded walkthrough of all features

## Evaluation Criteria

| Component | Weight | Evaluation Criteria |
|---|---|---|
| RAG Implementation | 20% | Vector search quality, retrieval accuracy, response relevance |
| Text Generation | 15% | Model fine-tuning, generation quality, prompt engineering |
| Image Generation | 15% | Integration quality, prompt optimization, image quality |
| System Architecture | 20% | Code quality, API design, scalability, error handling |
| Deployment | 15% | Cloud deployment, containerization, monitoring, documentation |
| Innovation & Features | 10% | Additional features, creative solutions, user experience |
| Presentation & Documentation | 5% | Demo quality, technical writing, communication |

## Expected Learning Outcomes

- Expertise in RAG systems and vector databases
- Proficiency in integrating multiple AI models
- Full-stack AI application development skills
- Cloud deployment and MLOps experience
- Production-ready AI system design
- Portfolio-worthy project for job applications
